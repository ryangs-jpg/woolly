# JEJU REF · Vercel 0.3

## 쉬운 검색·개인 ChatGPT 활용 (2026-11-06)

검색창에 짧은 목적을 적으면 700ms 후 공개 자료를 검색한다. 한국어 조합 중 호출을 보류하고, 입력이 바뀌는 순간 기존 요청을 취소·무효화해 늦은 응답을 표시하지 않는다. 새 라이브러리나 검색용 AI 호출은 추가하지 않았다. searchIntent의 제한된 규칙으로 카페·홍보·영상 등 소재와 매체를 확장하며, 감성 영상 → 바다처럼 보완한 소재는 화면에 제안으로 표시한다. 모든 자연어 의도를 이해하는 의미 검색은 아니다.

기본 자동 검색은 Commons와 TourAPI(키가 없으면 Openverse)를 병렬 조회한다. 결과가 모두 비면 Openverse의 제주 검색으로 한 번 확장하고 확대 여부를 표시한다. 한 출처 실패 시 다른 출처 결과를 유지한다. 5분 캐시·최대 24개 외부 결과·이미지 지연 로딩을 사용하며 캐시 DB 오류가 외부 검색 결과를 막지 않도록 처리한다. 외부 응답 실패·빈 결과에서는 기본 카탈로그임을 표시하고 참고자료를 유지한다. 제공사 응답 시간과 자료의 실제 목적 적합성은 보장하지 않는다.

담은 자료에서 ChatGPT용 내용을 복사하고 https://chatgpt.com/ 에 직접 붙여넣을 수 있다. 목적·최대 12개 자료의 제목/설명/태그/원본 출처/이용 조건을 포함하며 사진 파일은 첨부하지 않는다. 복사 실패 시 선택 가능한 본문을 표시한다. 사용자 계정 연결·자동 메시지 전송·추가 AI 호출은 하지 않는다. 저장은 기존 브라우저 세션 방식이다.

UI는 큰 본문·44px 이상 주요 버튼·명확한 키보드 포커스·접힌 상세 설정·모바일 단일 열 카드로 수정했다. 현무암 계열 짙은 색, 숲의 녹색, 감귤색 포인트를 사용한다. 실제 고령 사용자 사용성 시험이나 정식 접근성 인증을 수행한 것은 아니다.

## 배포 구성

- Vercel 프로젝트: woolly1 / jeju-ref-studio
- 프런트엔드: public → build-vercel.mjs → vercel-public
- 서버: api/[...path].js / Node.js
- 저장소: Neon 무료 플랜 PostgreSQL, server/neon-store.js
- 공개 이미지: Wikimedia Commons, Openverse
- 제주 관광·문화: 한국관광공사 TourAPI, 승인된 개발계정 키 연결 완료

운영 주소는 https://jeju-ref-studio.vercel.app 이며 Production 배포를 검증했다. Vercel Authentication 배포 보호가 적용되어 있다. 기존 Sites의 URL과 저장 데이터는 별도로 유지되며 자동 이관되지 않는다. Vercel 앱은 서명된 HttpOnly 방문자 쿠키로 보드를 분리한다. Vercel 로그인은 배포 보호이며 앱의 다중 기기 사용자 계정과는 다르다. 쿠키 삭제·다른 브라우저·다른 배포 호스트에서는 새로운 보드로 시작한다. 중요한 보드는 JSON으로 내보내 보관한다.

## 서버 환경변수

| 이름 | 용도 | 필수 |
|---|---|---|
| SESSION_SECRET | 방문자 세션 서명, 최소 32자 | 필수, Preview·Production 별도 값 |
| DATABASE_URL | Neon 서버리스 연결 | 서버 저장 시 필수 |
| TOURAPI_SERVICE_KEY | 한국관광공사 TourAPI 일반 인증키 Decoding 값 | 관광·문화 검색 활성화 시 필수 |

키는 Vercel 프로젝트의 Settings → Environment Variables에 서버 변수로 등록한다. 공개 접두사 NEXT_PUBLIC_ 또는 VITE_를 붙이지 않는다. 소스나 채팅에 붙이지 않는다. 환경변수 변경 후 해당 환경을 다시 배포한다.

## TourAPI 키 발급과 등록

1. https://www.data.go.kr/data/15101578/openapi.do 에서 한국관광공사 국문 관광정보 서비스_GW의 활용 신청을 진행한다.
2. 본인 계정 로그인·신청자 정보·활용 목적·약관 동의는 계정 소유자가 확인한다.
3. 승인 상태를 확인하고 일반 인증키의 Decoding 값을 Vercel의 TOURAPI_SERVICE_KEY에 등록한다.
4. 재배포 후 데이터 스튜디오의 ‘키 등록됨’을 확인한다. 이 표시는 값 존재 여부이며 실제 호출 성공은 검색으로 별도 검증한다.
5. 공개 API 출처를 TourAPI로 바꾸고 ‘해녀’, ‘박물관’ 등으로 검색한다.

검색 엔드포인트는 공식 자료의 KorService2/searchKeyword2를 사용하며 제주 법정동 지역 조건을 적용한다. 개별 사진의 권한은 별도로 처리한다. 현재는 응답의 Type1 사진만 미리보기를 표시하고 변경 제한 등 확인이 필요한 사진은 링크 카드로 제공한다. 로고·브랜드 표장 이용 제한은 원본 제공 조건을 확인한다. 키 없이 반환한 가상 관광 자료는 없다.

## API와 데이터

- GET /api/providers: 공개 API 출처·키 필요 여부·설정 여부, 비밀 값 제외
- GET /api/search?q=...&provider=commons|openverse|tourapi&offset=...
- GET /api/state: 현재 방문자 보드 복원
- POST /api/state: 같은 Origin, 기대 버전과 바인딩 SQL로 저장

미리보기는 각 자료의 원본·작가·라이선스 링크와 함께 표시한다. 자동 수집 자료의 제주 관계·학습 권한·검수 상태를 확정으로 승격하지 않는다. 메타데이터의 라이선스가 실제 권리 보유를 보장하는 것은 아니므로 원본 근거를 확인한다. 영상 분석·모델 학습은 미실행이다. 텍스트 기획안은 OpenRouter 무료 모델 연결을 사용한다.

## 개발과 마이그레이션

Vercel 연결과 환경변수 확인 후 다음을 실행한다.

```
node --env-file=.env.local scripts/migrate-neon.mjs
node --test tests/*.test.mjs
node build-vercel.mjs
```

Neon 마이그레이션은 user_state와 search_cache만 만들고 사용자 데이터를 시드하지 않는다. .env.local, .vercel, .local-data, 작업 폴더의 Vercel 인증 파일은 Git·배포 ZIP에서 제외한다. 기존 build.mjs는 Sites용이며 Vercel은 build-vercel.mjs를 사용한다.

## 오픈소스 추론 서버 연결

현재 상태: OpenRouter 무료 API 연결 완료. 실제 한국어 기획안 생성과 제공사 응답 비용 0달러를 확인했다. 직접 GPU 서버 구축·모델 학습은 미실행이다. 아래 직접 서버 절차는 대체 연결 방법이다.

1. 별도 추론 환경에 모델 라이선스와 하드웨어 요구사항을 확인한 뒤 vLLM 등 Chat Completions 호환 서버를 운영한다. Vercel 프로젝트는 모델 서버에 요청하는 웹 앱 역할이다. 서버 제공업체 가입·GPU 유료 자원 생성은 이번 작업에서 하지 않았다.
2. 모델 서버의 외부 접근은 HTTPS와 인증으로 보호한다. 추론 서버에서 인증키를 설정하고, Vercel 서버에서 접근 가능한 /v1 기본 주소와 정확한 모델 ID를 확인한다.
3. Vercel 서버 환경변수 INFERENCE_BASE_URL(예: https://inference.example/v1), INFERENCE_MODEL(실제 모델 ID), INFERENCE_API_KEY(Secret)를 등록하고 재배포한다. 이 예시 주소는 동작하는 서버가 아니다. 브라우저에 키를 입력하지 않는다.
4. 나의 보드에 출처가 있는 자료 1~12개를 저장하고 제작 목적을 입력한 뒤 AI 기획안 생성을 실행한다. 생성 버튼에는 원본 자료 메타데이터를 추론 서버에 전달한다는 안내가 있다.
5. 실제 모델에서 한국어 출력·[번호] 인용·허위 관찰·응답 시간·오류 처리를 검증한다. 출력은 사람이 검수할 초안이다. 이미지·영상 분석 및 학습은 별도 작업이다.

GET /api/inference는 비밀 값 없이 설정 존재 여부만 반환한다. POST /api/plan은 동일 Origin에서만 허용하고 메타데이터를 서버에 전달한다. 45초 타임아웃, 리다이렉트 차단, 일반 서버 최대 출력 토큰 2,200(OpenRouter 무료 연결은 4,096)이 적용된다. 현재 자료의 제목·태그·메모·라이선스·출처를 보내며 이미지 파일·개인 피드백은 전송하지 않는다. 생성 결과는 편집·복사·보드 내보내기로 보관할 수 있다. 별도 추론 운영자의 로그·보관 정책은 서버 구성 시 확인한다.

## 2026-11-05 무료 모델 연결

OpenRouter 키는 사용자 승인 후 90일 유효기간, 지출 상한 0달러로 발급했다. 만료일은 2027-02-03이며 만료 전 키 갱신이 필요하다. Production·Preview의 INFERENCE_API_KEY는 Secret이며 값은 저장소에 포함하지 않는다.

현재 설정은 INFERENCE_BASE_URL=https://openrouter.ai/api/v1 및 INFERENCE_MODEL=openrouter/free다. 앱은 OpenRouter 주소에서 openrouter/free만 허용하며 요청 provider.max_price의 prompt·completion을 각각 0으로 지정한다. 유료 모델 전환은 구현하지 않았다. 실제 응답 모델명을 결과에 기록하며 429는 무료 사용량·혼잡 안내로 표시한다. 무료 풀의 모델·제공 상황에 따라 지연·실패 또는 빈 응답이 발생할 수 있으며 안정적 처리량을 보장하지 않는다. 기본 일 50회 제한은 계정과 제공사 조건에 따라 확인해야 한다.

실제 연결 테스트에서 한국어 기획안 1,783자 및 usage.cost=0을 확인했다. 운영 UI에서도 레퍼런스 저장 → 제작 목적 입력 → AI 기획안 생성이 동작했다. 회귀 테스트 25개 통과. 토큰 한도로 잘린 응답은 incomplete로 구분해 재생성 안내를 표시한다. 이미지·영상 파일은 전송하지 않으며 영상 분석·모델 학습과는 별개다. 모델 출력의 사실과 라이선스는 사람이 검수한다.

## 학습 데이터 검수 (2026-11-05)

데이터 스튜디오에서 피드백을 제작 목적·평가 기준·원본 자료와 연결해 확인하고 검수 JSON 또는 JSONL로 내보낼 수 있다. 최신 목적·자료 ID·평가 기준별 평가를 선택하고, 출처 누락·상충 라벨을 표시한다. 같은 정규화 검색문·자료 ID·정규화 출처 URL을 공유하는 기록은 연결 요소 전체를 같은 분할 후보로 묶는다. source URL의 utm_*, fbclid, gclid와 해시를 제거하되 원본 식별에 필요한 쿼리는 보존한다.

분할은 연결 그룹 해시를 이용한 80:20 기대 비율의 검토용 제안이며, 소규모 자료에서 두 집합의 균형을 보장하지 않는다. 같은 그룹의 기록은 같은 후보에 남는다. 새 자료 추가로 연결 그룹이 합쳐질 수 있으므로 실제 학습 전에 데이터셋을 고정하고 분할을 다시 검증해야 한다. 행을 임의로 나눠 학습·평가 누수를 만들지 않는다. 동일 원본의 URL 별칭은 추가 수동 확인이 필요하다.

모든 내보내기 행은 training_ready=false, label_review_status=pending, training_permission=unverified, learning_consent=false다. 이것은 검수 자료이며, 학습 실행·검증된 정답 데이터로 간주하지 않는다. 쿼리·출처 URL이 포함되므로 공개 공유 전 검토한다. 내보내기는 브라우저에서 생성하며 모델이나 외부 학습 서버로 전송하지 않는다.

보드 저장·피드백이 참조하는 외부 메타데이터는 최대 300개 보관하며 보드 저장 자료를 우선한다. 누락된 참조는 검수 화면·내보내기에 명시한다. 같은 목적·동일 평가 기준에 관련 있음·없음이 모두 있는 목적을 보강 지표로 제공하며, 정확도 측정값으로 표시하지 않는다. 모델 학습·정량 검색 평가 실행은 별도 단계다.
